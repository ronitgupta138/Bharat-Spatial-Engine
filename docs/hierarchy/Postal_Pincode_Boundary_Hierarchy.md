# Indian Postal PIN Code Geographic Hierarchy

## 1. Six-Digit Structure
- **Digit 1:** Postal Zone (e.g. `7` = Eastern Zone: West Bengal, Odisha, North East).
- **Digit 2:** Sub-zone / Region.
- **Digit 3:** Sorting District within the state.
- **Digits 4–6:** Specific Delivery Post Office within the sorting district.
