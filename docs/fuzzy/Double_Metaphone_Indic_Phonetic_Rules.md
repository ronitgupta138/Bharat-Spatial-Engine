# Indic Place Name Double Metaphone Phonetic Rules

## 1. Consonant Normalization
- Collapses soft/hard dental consonants: `d` and `dh` mapped to canonical token `T`.
- Normalizes retroflex nasal consonants: `n` and `rn` mapped to `N`.
- Truncates terminal schwa vowels ('a' at word endings) typical in Hindi/Bengali transliterations.
